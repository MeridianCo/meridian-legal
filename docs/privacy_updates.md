# When to Update the Privacy Policy

Update the privacy policy **before** any of the following changes go live.

## Data Collection

- Collecting a new type of personal data (e.g. biometrics, voice, health data)
- Adding new device permissions (microphone, camera, contacts, calendar, etc.)
- Starting to collect data passively that wasn't collected before (e.g. location tracking)
- Collecting data from a new age group, especially minors under 18

## Third-Party Services

- Adding a new analytics provider (e.g. switching from or adding to Google Analytics)
- Adding a new payment processor alongside or instead of Stripe
- Adding a new AI provider alongside or instead of Google Cloud AI
- Adding any new service that receives user data (crash reporting, A/B testing, CRM, etc.)
- Adding new social login options (e.g. Apple Sign-In, LinkedIn)

## New Features

- Adding in-app purchases or subscriptions
- Adding a referral, affiliate, or rewards program
- Adding a chatbot, new AI feature, or any feature that processes user input
- Adding push notifications if not already disclosed
- Adding user-generated content (posts, comments, uploads)

## Data Handling Changes

- Changing how long user data is retained
- Storing data in a new country or region
- Sharing data with a new category of third party
- Selling, licensing, or monetizing user data in any way
- Changing how users can request deletion or export of their data

## Business Changes

- Company name or DBA change
- New contact email or mailing address
- New website URL
- Merger, acquisition, or asset sale
- Expanding operations to a new jurisdiction (especially EU, UK, California)

## Legal and Compliance

- A new privacy law comes into effect that applies to Meridian's users
- Receiving legal advice that the current policy is insufficient
- A data breach that requires disclosure obligations
- Any change to how consent is obtained from users
